# -Excel-Data-Visualization

A practical Microsoft Excel project focused on Data Visualization techniques used to analyze, interpret, and present business data effectively.

This project covers two important Excel topics:

-  Conditional Formatting
-  What-If Analysis

These exercises demonstrate how Excel can be used not only for calculations, but also for identifying patterns, highlighting important information, and evaluating different business scenarios.

---

Topics Covered

 1. Conditional Formatting

Conditional Formatting is used to automatically change the appearance of cells based on specific conditions or rules.

It helps users quickly identify important values, trends, exceptions, and patterns within a dataset.

Key Concepts Practiced

- Highlight Cells Rules
- Greater Than / Less Than conditions
- Duplicate Values
- Data Bars
- Color Scales
- Icon Sets
- Custom Conditional Formatting Rules
- Formula-based Conditional Formatting
- Applying formatting to business datasets

Practical Applications

Conditional Formatting can be used to:

- Identify high and low sales
- Highlight employees with exceptional performance
- Detect duplicate records
- Identify overdue tasks
- Compare business performance
- Highlight values above or below targets
- Visually analyze large datasets

---

 2. What-If Analysis

What-If Analysis is used to understand how changing one or more input values can affect the final result.

It is particularly useful for business planning, forecasting, budgeting, pricing, and decision-making.

Key Concepts Practiced

- Goal Seek
- Data Tables
- Scenario-based analysis
- Changing input variables
- Analyzing different outcomes
- Understanding relationships between inputs and outputs

 Practical Applications

What-If Analysis can be used to:

- Determine the sales required to reach a target profit
- Analyze different pricing strategies
- Calculate outcomes under different assumptions
- Compare business scenarios
- Perform financial planning
- Evaluate changes in costs, prices, or quantities
- Support data-driven business decisions
